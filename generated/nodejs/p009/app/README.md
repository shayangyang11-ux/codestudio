# 智能仓储管理系统

这是 CodeMind A9.10.7 根据 Development Build Context V1 生成的 Node.js 全栈项目。

## 运行

```bash
npm install
npm run build
npm test
npm start
```

## 资源接口

- `入库单创建页`: `/api/inbound-orders`
- `入库单列表页`: `/api/inbound-orders-2`
- `入库单详情页`: `/api/inbound-orders-3`
- `入库单数量编辑页`: `/api/inbound-orders-4`
- `入库单审核页`: `/api/inbound-orders-5`

## 说明

前端使用 Vue 3 + Vite，后端使用 Express + 本地内存数据层。业务页面来自用户已确认的 UI_CONTRACT，接口和数据层由 Development Agent 自动生成。
